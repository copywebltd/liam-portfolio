The problem

Foxelli runs seven DTC brands. Each one needed a steady stream of ad creative. The bottleneck wasn’t ideas. It was the gap between ‘we have an idea’ and ‘we have a finished video ad you can run on Meta tomorrow.’ That gap was eating my team’s week.

Architecture call I’d make again

The data layer and the media-generation layer are separated by design. Stateful business logic lives in Supabase where row-level security protects tenant data. Stateless heavy-lifting media calls run through n8n where queueing, retries, and provider fallback are trivial to wire. Splitting them by responsibility kept both layers honest.

// how I work

Five principles that decide what gets built and what doesn’t.

  1. Claude Code is the build environment, not the assistant. Every system in this portfolio shipped through Claude Code. Frontends, backends, agents, skills, MCP integrations, CLIs. Most people use AI to write code. I use it to ship systems.
  2. Humans stay in the chair. AI handles 90% of the heavy lifting. The human approves every output that touches a customer.
  3. Every system gets a learning loop. If it can’t get smarter from the work, I haven’t finished building it.
  4. Build the meta-tool. Don’t write a script when you can write the skill that writes the script. The leverage compounds.
  5. Run AI economically. Media generation routed through Kie.ai at ~60% under retail. Token discipline upstream. Cost-engineering an AI stack is engineering.
