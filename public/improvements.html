What you're seeing here

  1. 01Hero — centered, ~128px display headline, two-tone (white + grey). Single live-chip above the headline. Camera-vignette photo, more violet ambient. This is the BridgeMind/Vibecademy headline pattern.
  2. 02Trusted-by builder bar — green-dot eyebrow + 4 huge stat columns separated by hairline rules. Borrowed directly from BridgeMind's "9,700+ Discord · 70,000+ YouTube" bar.
  3. 03Artifact cards with inline product mockups — the load-bearing change. Foxelli Studio shows a kanban with auto-cycling cards (watch ~3 sec). LFSL shows a terminal typing the orchestrator command and ✓-marking each phase. This is what BridgeMind's BridgeSpace + BridgeVoice cards do.
  4. 04Stack as connected-clients diagram — left column = surfaces, center node = Claude Code runtime (with violet glow), right column = wired-in MCP servers. Animated dashed lines between them. BridgeMCP's "Connected Clients" pattern.

Animation tech used

  1. CSSPulse dots — `@keyframes pulse` on every live-chip indicator. Pure CSS.
  2. CSSDashed-line flow on the stack diagram — `stroke-dasharray` + `stroke-dashoffset` animation on SVG paths.
  3. JSKanban auto-cycle — vanilla setInterval shifts card text every 3.5s. In React this would be a `useState` + `setInterval` hook.
  4. JSTerminal typing — character-by-character append with setTimeout. Same pattern in React.
  5. CSSCursor blink — `@keyframes blink` step-end.

All animations here are CSS + ~30 lines of vanilla JS. No framer-motion, no lottie, no rive. Cheapest possible tier. To upgrade later: Lottie for hand-illustrated loops; Framer Motion `layout` prop for the kanban shift (smoother than setInterval); MP4 loop for one hero showpiece.
